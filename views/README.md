# WeRSS 网页预览模块

该模块基于Python FastAPI，为WeRSS项目提供网页预览功能，用于展示微信公众号文章、标签和公众号信息。它设计为现代化、响应式的用户界面，集成了搜索、筛选、排序和分页等功能。

## 📋 功能特性

### 🏠 首页
- **路由**: `/views/home`
- **功能**: 显示所有标签列表及相关统计。
- **特性**:
  - 卡片式布局展示标签
  - 显示公众号数量和文章数量统计
  - 分页浏览支持
  - 响应式设计

### 📄 文章列表页
- **路由**: `/views/articles`
- **功能**: 显示文章列表，支持丰富的筛选和排序。
- **特性**:
  - 关键词搜索 (标题/内容)
  - 多种排序方式（发布时间、创建时间）
  - 分页浏览
  - 阅读状态显示
  - 公众号信息展示

### 📖 文章详情页
- **路由**: `/views/article/{article_id}`
- **功能**: 显示文章完整内容及相关信息。
- **特性**:
  - 完整文章内容展示
  - 公众号信息
  - 原文链接（如果有）
  - 导航功能 (上一篇/下一篇)

### 👥 公众号列表页
- **路由**: `/views/mps`
- **功能**: 显示所有公众号列表，支持分页。

### 🏷️ 标签列表与详情页
- **路由**: `/views/tags` (列表) 和 `/views/tag/{tag_id}` (详情)
- **功能**: 显示所有标签列表，以及特定标签下的文章列表。

## 🚀 快速开始


## 🛠️ 技术实现

### 后端架构
- **框架**: FastAPI
- **数据库**: SQLAlchemy ORM
- **模板引擎**: 项目内置 `core.lax.template_parser`
- **响应类型**: HTMLResponse

### 前端设计
- **样式**: 内联CSS，现代化设计，渐变色主题 (#667eea 到 #764ba2)
- **布局**: CSS Grid + Flexbox
- **响应式**: 移动端友好

### 数据模型
- **Tags**: 标签分类信息
- **Articles**: 文章内容
- **Feed**: 公众号信息

## 📖 使用指南

- **导航**: 通过首页、文章列表和标签页面进行内容浏览。
- **搜索**: 在文章列表页使用关键词搜索文章。
- **筛选与排序**: 在文章列表页通过公众号ID、标签ID进行筛选，并按发布时间或创建时间排序。
- **分页**: 所有列表页支持分页浏览。
