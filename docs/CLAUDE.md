# Documentation Directory

## Overview

The `docs` directory contains project documentation, architectural diagrams, and user guides for the WeChat Mini Program RSS Reader system. This includes visual documentation, setup instructions, and feature explanations.

## Contents

### Architectural Documentation
- **架构原理.png**: System architecture diagram showing the overall structure and component relationships
- **前端架构.png**: Frontend architecture diagram illustrating the Vue.js application structure

### User Interface Documentation
- **主界面.png**: Main interface screenshot showing the primary user dashboard
- **登录.png**: Login interface documentation showing authentication flows
- **扫码授权.png**: QR code authorization process for WeChat integration
- **添加订阅.png**: Subscription management interface documentation
- **通知.png**: Notification system interface and configuration

### Project Assets
- **folo.webp**: Project logo or branding asset
- **赞赏码.jpg**: Donation or sponsorship QR code

### Development Documentation
- **github_update.md**: GitHub update procedures and release management
- **versions/**: Version-specific documentation and release notes
